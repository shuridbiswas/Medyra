# Quebec institution sources

The URLs below were supplied in the Medyra product specification as official references. They were **not re-fetched or re-validated by an engineer** during implementation, so `source_checked_at` is empty for every institution and must be set by a person who has read the page. Nothing here is a partnership or an API.

Status words: **Officially documented** (the institution publishes the procedure), **Integration requiring permission** (needs an agreement Medyra does not have), **Manual-only** (a Medyra reviewer does it by hand), **Unverified** (not researched). No integration has been successfully tested.

Where the program can be verified: only when official program evidence is provided and a reviewer confirms it. No institution-program pair is seeded; an administrator adds programs to `academic_programs` from the institution's official catalogue and sets `source_reviewed_at`.

## Federated login (future)

CANARIE Canadian Access Federation: https://www.canarie.ca/identity/caf/ and participants https://www.canarie.ca/identity/caf/participants/. Not implemented and not simulated. It would need service-provider registration, agreements and attribute validation, and an institutional login would still not prove a specific program unless trusted attributes say so. The registry records `FEDERATED_INSTITUTION_LOGIN` as `requires_permission` for every institution, and the request function refuses it.
